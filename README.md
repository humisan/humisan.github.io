# humisan のポートフォリオ

Javaでのプラグイン開発とMinecraftサーバーでの活動を紹介する個人サイトです。Next.jsの静的出力をGitHub Pagesで公開します。

## ページ

| パス | 内容 |
| --- | --- |
| `/` | アイコンと活動への入口 |
| `/about/` | 自己紹介、開発・運営、技術紹介 |
| `/servers/` | GankMC、LzPvP、日ノ本鯖の概要と担当役職 |
| `/links/` | GitHub、X、YouTube |
| `/play/` | 30秒のサングラス集め |
| `/play/dino/` | メガネ版Dino |
| `/play/rush/` | TARGET RUSH |
| `/news/` | お知らせ |

## 開発と検証

Node.js 22を使用します。

```sh
npm ci
npm run dev
```

開発サーバーが表示したURLをブラウザーで開きます。

```sh
npm run build
npm run typecheck
npm test
```

`npm test` はビルド済みの `out/` を検証するため、先にビルドしてください。ゲームの時間制限、重複キャッチ、配置範囲、不正な保存値と、静的出力のリンク・画像・404・公開内容を検証します。表示変更時は、スマートフォンとPCの実画面、日英切替、配色切替、キーボード操作も確認してください。

```sh
python3 -m http.server 3000 --directory out --bind 127.0.0.1
```

Python 3の標準サーバーで静的出力も確認できます。

## 表示と操作

- 上部のナビゲーションから各ページへ移動できます。
- JP / ENと昼夜の配色設定をブラウザー内に保存します。保存機能が使えない環境でも、その訪問中の切替は動作します。
- ホームのアイコンをクリックすると、きらめきを切り替えます。マウスの位置に合わせて画像が傾きます。
- サーバーを役職で絞り込み、公開されている参加アドレスをコピーできます。コピーを拒否された場合は、表示アドレスを手動でコピーします。
- ミニゲームのBGM「Summer Pixels」はオリジナルの軽いチップチューンです。開始時に再生し、一時停止・終了・ページ移動で停止します。音量とミュートを変更できます。ブラウザーで再生を拒否された場合もゲームは動作します。
- サングラス集めはタップ・クリック、TabとEnterで操作できます。Dinoはスペース・上矢印・タップでジャンプし、下矢印でしゃがみ・急降下します。TARGET RUSHはクリック・タップ専用で、TabやEnterでは命中しません。
- サングラス集めとTARGET RUSHは30秒、Dinoは衝突で終了し時間制限はありません。Google版の初速・加速・最高速・距離スコアに合わせています。
- サングラス集めとDinoは別タブに移ると一時停止します。TARGET RUSHは不公平な中断を防ぐためプレイを終了します。
- 各ゲームに公開ランキングがあります。開始にはランキングAPIへの接続が必要です。通信失敗時は再試行できます。
- OSで「視差効果を減らす」を有効にすると装飾アニメーションを停止します。

## 内容の更新

自己紹介・サーバー紹介・SNSは `app/components/PortfolioPages.tsx` にあります。共有テキストは `app/context/LanguageContext.tsx`、見た目は `app/globals.css` で管理します。日英両方の表示を更新してください。

サーバーの役職は本人から提供された情報を使用しています。公開情報の参照元は [GankMC公式サイト](https://www.gankmc.com/) と [LzPvPの公開紹介](https://modrinth.com/server/lzpvp) です。個別プラグイン名、未確認の経歴、プレイヤー数、稼働状況は掲載しません。日ノ本鯖の参加アドレス・公式リンクは未提供のため掲載していません。

## 公開と復旧

`main` へのpushでGitHub Actionsがビルドと検証を実行し、`out/` を `gh-pages` に配置します。独自ドメインは `hanyuu.lol` です。

公開変更を戻す場合は、対象コミットをrevertするPRを作り、同じ検証を通してから `main` に統合してください。GitHub履歴を書き換える必要はありません。リニューアル前のソース・公開ファイル・Git履歴のバックアップは、今回の作業チャットの成果物として別途保存しています。

フロントエンドは静的ファイルです。ランキングAPIはCloudflare WorkersとSQLiteを使うDurable Objectで公開しています。認証情報はフロントエンドに含めません。

## Dinoとお知らせ

`/play/dino/`でスペースキー・上矢印・タップでジャンプするメガネ版Dinoを遊べます
障害物に当たると終了し、自己ベストを端末に保存します

## 公開ランキング

3ゲームの記録は別々に保存し、同じ公開名の最高記録だけ表示します
上位50件を表示し、各ゲーム上位200件を保持します
公開名は本人認証を行わないニックネームです

サーバーが発行したプレイID・乱数と操作履歴からスコアを検証します
クライアントが申告したスコアは使いません
不正な形式・過剰な操作・未完了のラウンド・期限切れ・重複登録を拒否します
同じ接続元からの開始は10分に12回、登録は10分に10回までです
Dinoの途中検証は10分に120回までです
IPアドレスをそのまま保存せず秘密のソルトでハッシュ化し、短期間の制限とプレイ照合にのみ使います
登録は結果が出てから2分以内に行ってください
通信タイムアウトは12秒で、自動再送は行わずボタンから再試行します
自動操作を完全に判別する仕組みではありません

### APIの開発と公開

Wrangler 4.45.0を使用します
ローカルの`worker/.dev.vars`に`RATE_LIMIT_SALT`を設定します
フロントの`.env.local`には`NEXT_PUBLIC_GAMES_API=http://127.0.0.1:8787`を設定します
秘密のファイルはGit管理から除外されています

```sh
npx wrangler@4.45.0 dev --config worker/wrangler.jsonc --port 8787 --var ALLOW_LOCAL:true
node --test worker/integration.test.mjs
```

結合テストはローカルAPIにテスト記録を作ります
本番には実行しません
本番ビルド時は`.env.local`のAPI指定を外し、既定の本番APIを使用します

```sh
npx wrangler@4.45.0 deploy --config worker/wrangler.jsonc
```

`RATE_LIMIT_SALT`と`MODERATION_KEY`はCloudflareのsecretとして保存しています
不適切な公開名の記録は管理キーを使って削除できます
キーの内容をログやコマンド引数に直接渡さないでください

```sh
node worker/moderate.mjs --game rush --name "削除する公開名" --key-file "$RANKING_KEY_FILE"
```

フロントエンドはPRのrevert、WorkerはCloudflareの前バージョンへのrollbackで戻せます
既存のランキングデータは削除しません

## DinoのGoogle版ルール

Google版の設定値・操作と衝突形状を基準にしています
メガネの描画、BGM、サイトのランキング画面はこのサイトのものです
詳細と参照元は`docs/dino-reference.md`にあります

Dinoは15秒ごとに操作履歴をAPIへ送り、サーバー側で同じ状態を再現します
1回の検証は最大60秒分で、長時間のゲームをまとめて検証する必要はありません
通信失敗時は同じ区間を再送でき、重複によってスコアが増えることはありません
ゲーム終了時の検証が済むと登録フォームが表示されます

新ルールは`dino-v2`として別のランキングに保存し、以前の`dino`の記録と検証処理は残しています
